# 阶段 B 验收记录

执行日期：2026-09-27。分支：`codex/stage-b`。基于阶段 A 的图片与中文字体验证，交付可编辑、可保存、可恢复的本地简历流程。

## 已实现

- 新建、结构化编辑、重命名、复制和删除简历；教育、经历、项目、技能、自定义模块；模块排序 / 隐藏和手动分页。
- 正文段落、项目列表、加粗；HTML 转义。两个页眉模板、两种本地中文字体、有限的字号 / 行距 / 间距 / 页边距调整。
- PostgreSQL/Flyway 持久化正文、版式、版本与附件元数据。数据库仅绑定本机开发端口 18766，使用独立卷 `local-resume-dev_resume_pgdata`。
- 自动保存状态区分待保存、保存中、已保存和保存失败。串行写入、乐观修订检查、最近一次 mutation ID 重试；冲突可保留为副本。
- 初始版本、手动版本、恢复前自动快照和导出快照；当前引用与历史引用分别有数据库外键。移除 / 替换图片不删除历史文件。
- 共享分页脚本等待字体与图片就绪后测量真实高度。长条目可在列表项 / 段落之间续页；导出绑定持久版本，不混入之后的编辑。

## 数据库故障与真实重启

创建包含照片 / Logo / 两页内容的持久化样本，并创建“重启前快照”。之后执行了：

1. 只停止本项目的 PostgreSQL 容器，读取简历返回 HTTP 503 / DATABASE_UNAVAILABLE。
2. 用原卷启动 PostgreSQL，再重启本项目 Java 应用。
3. 比较重启前后整个简历记录，内容、修订和时间字段一致。
4. 历史快照 ID 仍可查到；两张标准化 PNG 与元数据里的 SHA-256 一致。
5. 从同一已保存修订重新创建导出快照并成功生成 PDF。

机器记录：`output/database-outage.json`、`output/restart-verification.json`。测试过程未删除数据卷、未修改其他项目容器。工作区保留了这份合成样本供继续编辑。
