# 导入 Word 简历

此功能在当前源码版提供；已发布的 v0.8.0 Docker 镜像尚不包含 Word 导入。使用 Windows 源码启动方式构建当前版本后，可以在「我的简历」页面找到「导入 Word」。

## 怎么使用

1. 点击「导入 Word」，选择不超过 5 MiB 的 `.docx` 文件。
2. 点击解析，查看提取的原文、基本信息和模块。文件在本机处理，不需要模型密钥，也不会发送给模型服务。
3. 核对姓名、求职方向、联系方式和模块归类。可以修改模块类型、标题和段落；未归类的文字会保留，识别不确定的内容需要人工确认。
4. 填写新简历名称，确认创建。新简历会在普通编辑器中打开，已有简历保留。
5. 调整模板、文字和间距；需要时上传照片与学校 Logo，再预览并导出 PDF。导入后的简历可以继续编辑、保存历史版本，以及通过完整备份迁移。

解析或核对阶段可以取消，此时不会创建简历。创建结果尚未确认时，请保留窗口并点击「重试创建」；重试会确认同一请求，避免生成重复简历。完成后删除导入的简历，旧创建请求也不会将其重新建立。

## 支持范围

支持提取正文段落、表格中的文字、文本框、链接的显示文字，以及页眉页脚文字。按教育、工作／实习、项目、技能等标题识别模块，其余内容保留供核对。较长的段落可能拆分为多个可编辑段落，窗口会提示。

导入用于整理文字，Word 的字体、颜色、列布局和内嵌图片不会直接转换。请在工作台中选择模板、调整排版，并单独上传照片和 Logo。链接只读取显示文字，不访问链接目标。

旧版 `.doc`、加密文件、带宏的文档和 PDF 暂不支持；可以先用 Word 另存为无密码的 `.docx`。损坏文件、没有可读取文字或内容超过限额时会给出错误提示，已有简历不受影响，原始 Word 文件也保留。篇幅很长的文件即使导入成功，导出 PDF 时仍可能需要缩短单条内容或调整分页。
