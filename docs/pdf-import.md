# 导入 PDF 简历

从 0.9.0 起，在「我的简历」页面点击「导入 PDF」。当前源码版另提供内嵌图片手动选择；已发布的 0.9.0 镜像尚未包含图片选择。

## 怎么使用

1. 选择不超过 5 MiB、文字可以选中和复制的 `.pdf` 文件。
2. 查看提取的原文和页数，再逐项核对姓名、联系方式、教育、经历、项目及技能。分类不确定的文字会留在可编辑模块中。
   页眉有独立一行，仅含一组邮箱和手机号（可带标签、分隔符）时，工作台会尝试预填这两个字段并提示核对；混有其他文字的行保留在核对内容中。
3. 当前源码版如显示图片候选，请辨认缩略图后明确选择证件照或学校 Logo，也可以全部不选。按需改正字段、模块类型、标题和段落，填写新简历名称后点击确认。应用会新建一份简历并打开普通编辑器，已有简历保持完整。
4. 在编辑器里选择模板、调整文字和间距。选中的图片会进入新简历的初始历史版本；未显示为候选的图片请按需要重新上传。完成后可导出新的中文 PDF，或下载完整工作区备份。

解析和核对都在本机完成，不需要账号或模型密钥，也不会将文件发送给模型服务。取消或解析失败不会创建简历；原 PDF 仍在你选择它的位置，工作台不会保存原文件。创建结果尚未确认时，保留窗口并点击「重试创建」，以便使用同一请求确认结果。

## 适用范围

目前只处理含有可选择文字的 PDF。扫描件、只有图片或已把文字转成轮廓的文件无法提取正文，会显示明确提示；此功能不执行 OCR。加密文件需要先在 PDF 阅读器中解锁并另存。超过页数或文字限额、文件损坏时也不会悄悄截掉内容。

PDF 的列布局与字号不直接复制进简历。当前源码版只显示可安全解码且大小受限的内嵌图片，缩放成适合简历使用的副本供手动选择；过大、重复、损坏或无法识别的图片仍需单独上传。多栏、表格或浮动文本的提取顺序可能与视觉顺序不同，请根据原文核对窗口逐条检查，再决定是否创建。导入成功后仍可能因内容过长在重新导出时提示分页超限，可在编辑器中缩短单条内容或调整排版。
